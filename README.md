# MyPadel

Privat overblik over DPF-turneringer, Lunar Liga og ledige padelbaner.

Siden hentes automatisk fra Rankedin (og Padelmates) hver 3. time af GitHub Actions
(`.github/workflows/update.yml`) og udgives med GitHub Pages. Du kan også starte en
opdatering selv under fanen Actions, "Opdater MyPadel", "Run workflow".
